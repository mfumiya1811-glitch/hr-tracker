# 製薬業界 人事異動トラッカー

製薬各社の**公式発表**から、経営層・管理職以上の人事異動を収集・整理して一覧できるようにしたものです。

公開URL: `https://<ユーザー名>.github.io/hr-tracker/`
（閲覧にはログインが必要です）

## 何ができるか

- 複数社の人事異動を**横断的に検索・ソート**
- 発表日から異動日までの**経過日数**を自動計算
- **CSV / JSON でエクスポート**
- AI が抽出した候補を**承認・却下するレビュー画面**
- 各社の**取得可否と最終巡回日**を一覧（拾えていない企業が見える）

## 収集対象

| 企業 | 状態 | 形式 | 備考 |
|---|---|---|---|
| グラクソ・スミスクライン | 対象 | HTML | URLが `/YYYYMMDD-hr/` で規則的 |
| 第一三共 | 対象 | PDF | リンク文言で判定。`pdftotext -table` で抽出 |
| エーザイ | 対象 | HTML | 人事表が最も充実 |
| 中外製薬 | 対象 | HTML | — |
| 塩野義製薬 | 対象 | HTML | 年1回程度 |
| 武田薬品工業 | 対象外 | — | 一覧がJavaScript描画で取得できず |
| アステラス製薬 | 対象外 | — | 人事記事の所在が未特定 |

**対象外としたソース**

- ミクスOnline … robots.txt が AI クローラーを明示的に拒否
- LinkedIn … robots.txt が自動アクセスを明示的に禁止。加えて個人情報
- 日刊薬業 … 冒頭のみ無料で以降は会員限定（有料購読）
- 官報 … 株式会社の役員変更は商業登記簿であり官報には載らない

## データの扱い方（重要）

- **発表日** = プレスリリースの掲載日。**異動日**（原文の「〜付」）とは別物です
- **部署名は推測で埋めません**。原文に無い場合は空欄のままにします
- 全レコードに**出典URLと原文の抜粋**を保存しています。承認前に必ず突き合わせてください
- 「退任」「辞任」は原文で使い分けられているため、両方を拾って備考に原文表記を残します

## ファイル構成

```
index.html                      画面本体
style.css                       デザイン
config.js                       Supabase 接続設定（公開用キー。公開して問題なし）
config.example.js               その見本

schema.sql                      DBの初期構築
schema-02-login-required.sql    閲覧をログイン必須にする変更

start.ps1                       ローカルで画面を開く
setup.ps1                       初回セットアップ
test-connection.ps1             接続確認
lib.ps1                         共通処理（.env 読み込み・API呼び出し）

.env                            秘密キー（Git管理外）
```

## ローカルで動かす

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1
```

`http://localhost:3000` で開きます。
`index.html` を直接ダブルクリックしないでください。`file://` ではログインが戻ってきません。

## セキュリティ

- `config.js` の公開用キー（`sb_publishable_`）は**公開前提**の設計です
- RLS により、**ログインしない限りどのテーブルも一切読めません**
- 秘密キー（`sb_secret_`）は `.env` にのみ置き、Git管理外です
- 記事の原文全文（`articles` テーブル）は未ログインでは参照できません
